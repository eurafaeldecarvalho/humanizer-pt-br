# Exemplos

Os dez gêneros da vitrine. Cada pasta é cópia de `eval/textos/ia/`, gerada por `scripts/build.py`. O texto é fictício, escrito por Grok 4.7 em 2026-10-29 para este repositório. A reescrita é do mesmo modelo, no mesmo dia.

`mudancas.md` lista as heurísticas que dispararam no antes e no depois. `meta.yaml` guarda o prompt.
