# Arquivinho Copia Pastas Sem Drama

No mundo atual, cópia ainda é o backup. O arquivinho endereça o problema de levar uma pasta para um disco externo. É uma plataforma completa, ponta a ponta.

```
arquivinho copiar ~/Documentos /mnt/backup --desde 2026-10-01
```

Não apaga a origem. Não cifra os arquivos. Feito em Go 1.22. Vale pontuar que o comando acima é o caminho feliz.
